# ReForge v0.6.0

Adds the existing Forge-X QEMU API probe and N32G455 board simulator drafts.
The probe uses working copies of local firmware images, binds host forwards to
loopback, keeps Phobos on a private database and terminates only its own guest.
Captures default to the ignored harness build directory. No firmware feature
changes are included. Release checks also remove unused build variables, guard
a temporary-directory change and document intentional PID-1 handoff linting.

Verification: the board protocol self-test, host unit suite and ShellCheck
(97 scripts, no warnings) pass. Packaging smoke uses the cached rootfs; the
full firmware image was not rebuilt. The QEMU
guest reaches Klippy ready; server info, printer info, update status and file
roots return HTTP 200. The captured optional notifier and analysis endpoints
return 404 on this Forge-X Moonraker fixture. The QEMU check did not include
Phobos; its optional injection path remains unverified.

This is a local source release. No remote is configured, so the existing
tag-triggered production workflow cannot be published or dispatched. No printer
firmware was installed.
