# ReForge v0.8.0

- Updated the firmware base to Buildroot 2026.08.2 and pinned OpenSSL to 3.5.9 LTS.
- Updated the optional HelixScreen package to 1.0.11 and verified its first-run
  render in QEMU. The default image still uses GuppyScreen.
- Updated the experimental Linux size proxy to 7.3.5. Installed firmware still
  uses the printer's stock kernel.
- Corrected setup, boot, recovery, and update instructions. Separated current
  recipes from the versions used to produce earlier lab results.

Use `reforge-0.8.0.tgz` to install the new root filesystem and base libraries.
The component OTA archives update applications and `/mod`.
[USB installer instructions](https://github.com/maci0/reforge/blob/v0.8.0/packaging/README.md#install-flow).
